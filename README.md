| macOS    | Intel x64 | `Overclock-X.Y.Z.dmg` |

## Install (macOS, soft launch)

This build is **ad-hoc signed** (no Apple Developer ID yet). First launch:

1. Download the `.dmg` matching your Mac.
2. Open the DMG and drag **Overclock** to Applications.
3. **Right-click** the app in Applications → **Open** → confirm the Gatekeeper dialog.
4. Subsequent launches open normally.

## Auto-update

Once installed, the app checks for updates automatically on launch and every 4 hours. You'll get a prompt to restart when an update is ready.
